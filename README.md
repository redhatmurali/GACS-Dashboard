# GACS Dashboard + GenieACS

Easy installation scripts for **GenieACS** and **GACS Dashboard**.

## 🚀 Install GenieACS

Download:

[**Download install-genieacs.sh**](https://raw.githubusercontent.com/redhatmurali/GACS-Dashboard/main/install-genieacs.sh)

Or run:

```bash
curl -fsSL https://raw.githubusercontent.com/redhatmurali/GACS-Dashboard/main/install-genieacs.sh -o install-genieacs.sh
chmod +x install-genieacs.sh
sudo ./install-genieacs.sh
